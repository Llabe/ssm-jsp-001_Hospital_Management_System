# SSM-Jspssm576中小型医院管理系统

#### Description
基于SSM（Spring+SpringMVC+MyBatis）架构的医院管理系统，整合JSP+ElementUI+LayUI前端技术，实现患者挂号、处方管理、住院登记等核心业务功能，支持多角色权限控制与在线支付能力。
